결제 내역 페이지
================

■ 무엇인가
계정의 결제·구매 내역을 보여 주는 단일 HTML 페이지입니다. 결제 수단 / 정기 결제 / 예산 및 주문 내역 탭이 있고,
지금은 '예산 및 주문 내역' 화면이 열려 있습니다.
내역은 자동으로 들어오지 않고, 화면에서 직접 추가·편집합니다.

■ 여는 방법
index.html 을 두 번 클릭하거나 브라우저로 끌어다 놓으면 됩니다.
파일 하나에 아이콘·글꼴·국기·파비콘이 모두 들어 있어서 이 파일만 있으면 어디서든 똑같이 열립니다.

■ 주문 추가
1) '주문 내역' 오른쪽의 [+ 주문 추가]를 누릅니다.
2) 상단 '빠른 상품'에서 dia_01_dn ~ dia_06_dn 중 하나를 고르면
   상품명·금액·아이콘이 한 번에 채워집니다. 직접 입력해도 됩니다.
   상품명, 날짜, 금액(원/달러), 상태(취소됨·환불됨), 아이콘을 채웁니다.
   - 아이콘은 목록에서 고르거나, 이미지 파일을 올리거나, 이미지 주소를 넣을 수 있습니다.
   - 업로드한 이미지는 128px 정사각형으로 줄여 저장됩니다.
3) '추가 개수'에 3을 넣고 저장하면 같은 주문이 3건 들어갑니다.
4) 저장하면 목록 맨 아래에 붙고, 월 지출액이 자동으로 다시 계산됩니다.

■ 캡쳐
'주문 내역' 오른쪽 [캡쳐]를 누르면 편집용 버튼과 행 도구를 숨긴 상태로 화면 전체를 PNG로 저장합니다.
파일은 order-history-YYYYMMDD-HHMM.png 이름으로 내려받기 폴더에 저장됩니다.

■ 외부에서 접속
python serve.py 8000 0.0.0.0 로 띄우고, 같은 네트워크에서는 http://<PC IP>:8000 으로 엽니다.
외부(인터넷)에서 열려면 포트 포워딩이나 터널이 필요합니다 — REQUEST.md 참고.

■ 행 편집
각 행 오른쪽 도구로 처리합니다.
  ↑ ↓    순서 위/아래로
  복제   같은 주문을 한 번 더 추가
  편집   내용 수정(편집에서는 개수 칸이 숨겨짐)
  ✕      삭제

■ 데이터
- 입력한 내용은 이 브라우저 저장소에 남습니다(새로고침해도 유지).
- 다른 기기·브라우저로 옮길 때는 모달 아래 [JSON 내보내기]로 파일을 받아,
  옮길 곳에서 [JSON 가져오기]를 쓰면 됩니다(기존 목록은 교체됨).
- [전체 삭제]는 확인 후 모두 지웁니다.

■ 파일 구성
index.html                 결과물 — 이 파일만 있으면 동작
BRIEF.md                   빌드 요청서(다른 사람·도구에 작업을 넘길 때)
docs/preview.png           빈 화면 미리보기
docs/preview-form.png      주문 추가 화면 미리보기
tools/app.js               화면 동작 스크립트(편집 UI 전부)
tools/app.css              편집 UI 스타일
tools/build_app.py         페이지 빌드 스크립트
assets/                    빌드에 쓰는 원본 자산
주문 내역 - Google Play.html, 주문 내역 - Google Play_files/   원본 저장본(수정하지 않음)

■ 고칠 때
- 문구·동작은 tools/app.js, 스타일은 tools/app.css 를 고친 뒤
  python tools/build_app.py 로 index.html 을 다시 만듭니다.
- index.html 을 직접 고쳐도 되지만, 다시 빌드하면 덮어써집니다.
- 행 구조(클래스 RqCJic, bBW4qb, D9le5c, SKMdtf, mshXob 등)는 페이지 기본 스타일과 묶여 있으니
  이름을 바꾸지 않는 편이 안전합니다.
