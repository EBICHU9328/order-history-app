결제 내역 페이지
================

■ 무엇인가
계정의 결제·구매 내역을 보여 주는 단일 HTML 페이지입니다. 결제 수단 / 정기 결제 / 예산 및 주문 내역 탭이 있고,
지금은 '예산 및 주문 내역' 화면이 열려 있습니다.
내역은 자동으로 들어오지 않고, 화면에서 직접 추가·편집합니다.

■ 여는 방법
index.html 을 두 번 클릭하거나 브라우저로 끌어다 놓으면 됩니다.
파일 하나에 아이콘·글꼴·국기·파비콘이 모두 들어 있어서 이 파일만 있으면 어디서든 똑같이 열립니다.

■ 주문 추가
1) '주문 내역' 오른쪽의 [+ 주문 추가]를 누릅니다.
2) 상단 '빠른 상품'에서 dia_01_dn ~ dia_06_dn 중 하나를 고르면
   상품명·금액·아이콘이 한 번에 채워집니다. 직접 입력해도 됩니다.
   상품명, 날짜, 금액(원/달러), 상태(취소됨·환불됨), 아이콘을 채웁니다.
   - 아이콘은 목록에서 고르거나, 이미지 파일을 올리거나, 이미지 주소를 넣을 수 있습니다.
   - 업로드한 이미지는 128px 정사각형으로 줄여 저장됩니다.
3) '추가 개수'에 3을 넣고 저장하면 같은 주문이 3건 들어갑니다.
4) 저장하면 목록 맨 위에 쌓이고(최신이 위), 월 지출액이 자동으로 다시 계산됩니다.

■ 캡쳐
'주문 내역' 오른쪽 [캡쳐]를 누르면 편집용 버튼과 행 도구를 숨긴 상태로 화면 전체를 PNG로 저장합니다.
파일은 order-history-YYYYMMDD-HHMM.png 이름으로 내려받기 폴더에 저장됩니다.

■ 접속 주소
https://ebichu9328.github.io/order-history-app/
PC가 꺼져 있어도 열립니다. 휴대폰·다른 PC에서 같은 주소를 쓰면 같은 내역이 보입니다.

주소를 아는 사람은 누구나 열람·수정할 수 있습니다(로그인 없음).
페이지 소스에 동기화용 GitHub 토큰이 들어 있어, 그 토큰으로는 이 계정의 gist·저장소에 접근할 수 있습니다.
내역 자체는 secret gist 에 저장되어 검색으로는 잘 드러나지 않습니다.

■ 기기 간 동기화
추가·수정·삭제가 1초 안에 서버(gist)에 올라가고, 다른 기기는 3초마다 확인해 자동 반영합니다.
'주문 추가' 왼쪽 점이 상태 표시입니다 — 회색: 대기, 노랑: 올리는 중, 초록: 정상, 빨강: 실패(오프라인).
빨강이어도 이 기기에는 저장되며, 연결되면 다시 자동으로 올라갑니다.

■ 다른 방식으로 띄우기(로컬 서버)
python serve.py 8000 0.0.0.0 으로도 띄울 수 있습니다. 단 이 경우 기기 간 동기화는 되지 않습니다.

■ 게임에서 자동 기록 (훅)
게임/모드에서 구매가 일어날 때 아래 한 줄을 부르면 그 항목이 자동으로 올라갑니다.

    python hooks/log_purchase.py dia_06_dn

모드가 로그를 남기게 했다면 그 로그를 감시하는 방식이 가장 간단합니다.
  모드: Log.d("DKSHOP", "PURCHASE dia_06_dn") 처럼 태그 DKSHOP + 상품 코드
  PC:   python hooks/watch_adb.py --tag DKSHOP
HTTP 로 받으려면 `python hooks/log_purchase.py --serve` (로컬 전용, 에뮬레이터는 `adb reverse tcp:8770 tcp:8770`).
PC 파일 로그면 `python hooks/watch_log.py --file <로그경로>`.
상품 코드·금액 표는 `hooks/purchase_codes.json`, 자세한 사용법은 `hooks/README.md`.

■ 초기화
'주문 내역' 오른쪽 [초기화]를 누르면 확인 후 목록을 전부 지웁니다. 다른 기기에도 바로 반영됩니다.
모달 아래 [전체 삭제]도 같은 동작입니다.

■ 행 편집
각 행 오른쪽 도구로 처리합니다.
  ↑ ↓    순서 위/아래로
  복제   같은 주문을 한 번 더 추가
  편집   내용 수정(편집에서는 개수 칸이 숨겨짐)
  ✕      삭제

■ 데이터
- 입력한 내용은 이 브라우저 저장소에 남습니다(새로고침해도 유지).
- 다른 기기·브라우저로 옮길 때는 모달 아래 [JSON 내보내기]로 파일을 받아,
  옮길 곳에서 [JSON 가져오기]를 쓰면 됩니다(기존 목록은 교체됨).
- [전체 삭제]는 확인 후 모두 지웁니다.

■ 파일 구성
index.html                 결과물 — 이 파일만 있으면 동작
BRIEF.md                   빌드 요청서(다른 사람·도구에 작업을 넘길 때)
docs/preview.png           빈 화면 미리보기
docs/preview-form.png      주문 추가 화면 미리보기
tools/app.js               화면 동작 스크립트(편집 UI 전부)
tools/app.css              편집 UI 스타일
tools/build_app.py         페이지 빌드 스크립트
assets/                    빌드에 쓰는 원본 자산
주문 내역 - Google Play.html, 주문 내역 - Google Play_files/   원본 저장본(수정하지 않음)

■ 토큰이 만료되면
페이지에 심어 둔 GitHub 토큰이 만료되거나 취소되면 동기화 점이 빨강으로 바뀝니다.
1) 터미널에서 gh auth login 으로 다시 로그인
2) printf 'protocol=https\nhost=github.com\n\n' | git credential fill 로 나온 password 값 확인
   (gh auth token 은 값을 축약해서 보여 주므로 쓰지 않습니다)
3) 그 값을 tools/sync.json 의 token 에 넣고 python tools/build_app.py 로 다시 빌드
4) git add -A && git commit && git push — 1~2분 뒤 배포에 반영됩니다

■ 고칠 때
- 문구·동작은 tools/app.js, 스타일은 tools/app.css 를 고친 뒤
  python tools/build_app.py 로 index.html 을 다시 만듭니다.
- index.html 을 직접 고쳐도 되지만, 다시 빌드하면 덮어써집니다.
- 행 구조(클래스 RqCJic, bBW4qb, D9le5c, SKMdtf, mshXob 등)는 페이지 기본 스타일과 묶여 있으니
  이름을 바꾸지 않는 편이 안전합니다.
